# 晶圆检测微力控制工程手册

## 0. 文档定位与适用边界

本文面向半导体晶圆检测设备的机械与运动控制工程师，讨论在克力级到微牛级接触力要求下，Z 向执行元件从接触式气缸切换到气膜支撑式低摩擦气缸的工程实现方法。内容覆盖指标定义、机理推导、四个典型工位集成、气源规范、检查清单与故障排查。文中参数取自整机调试与出厂验收记录；不同缸径、不同供气条件需按实际换算，不可直接套用。

## 1. 设备约束：三项硬指标与一条隐性约束

晶圆检测（AOI、探针台、膜厚与线宽量测、EFEM 上下料）对 Z 向执行元件提出三类耦合约束：

| 指标 | 量化要求 | 不达标的后果 |
| --- | --- | --- |
| 接触力可控性 | 0.01N 级（约 1 克力），可分辨 2.4g 级台阶 | 针痕过深、焊盘击穿、碎片 |
| 低速匀速性 | 0.5mm/s 以下无爬行，速度波动 ≤ ±0.1mm/s | 对焦振荡、测点漂移、数据不可信 |
| 位置稳定性 | 重复定位 ≤ ±0.005mm | 测点偏移、重复测量不一致 |

隐性约束是洁净与无油：Class 100 环境下不允许排气带油雾，接触式润滑脂方案因此受限。这条约束往往在方案后期才暴露，改造成本高于前期直接选对结构。

## 2. 最小可控力的量化推导

选型阶段先算一笔硬账。气缸的理论输出力与供气压力成正比：

```
F = P × A
A = π × (D/2)²
```

以 16mm 缸径为例，A ≈ 2.01 cm²。按 JB/T 5923 的空载起动压力 0.1MPa 计，最小可建立推力约 20N。即便把调压阀调到最低可用压力，输出力下限仍停在 20N 量级，力控只能做到数牛到数十牛，与克级需求差约三个数量级。缩小缸径不是解法：缸径越小，摩擦占比越高，低速爬行越严重。

第二笔账是摩擦。接触式气缸的静摩擦与动摩擦之差通常在数牛量级，这个差值构成力死区：气压增到差值之前活塞不动，越过之后突然起动，低压力段的分辨率被整段吃掉。行业实测的爬行临界速度多在 50mm/s 附近，低于该速度后速度曲线出现锯齿。

## 3. 气膜支撑的工程实现

### 3.1 三条必要条件

- 缸壁表面粗糙度 Ra ≤ 0.02μm。粗糙度决定气膜厚度的一致性，Ra 偏大会让局部间隙被短路，承载能力下降。
- 持续供气形成气膜。活塞与缸壁之间由微米级气膜隔开，金属不直接接触，静摩擦与动摩擦的差值被压到接近零。
- 动态压力补偿。缸内气路随行程自动补偿压力分布，避免行程末端气膜塌陷。

### 3.2 参数基线

| 参数 | 指标 |
| --- | --- |
| 静态摩擦系数 | ≤ 0.0005 |
| 动态摩擦系数 | ≤ 0.001 |
| 最低启动气压 | 0.05MPa（垂直单作用 0.03MPa 即可启动） |
| 启动响应 | ≤ 10ms |
| 速度控制精度 | ±0.1mm/s |
| 最佳工作压力 | 0.15~0.60MPa（最大 0.7MPa） |
| 设计寿命 | 1 亿次 |

摩擦系数压到千分之一量级后，力分辨率不再受摩擦死区限制，转而由上游压力分辨率决定：PPR 隔膜式精密调压阀分辨率 0.12KPa，独立于先导压力和流量，作用在 ULF16S 上约 2.4g，作用在 ULF40S 上约 15g。0.01N 级的来源不是标称值堆砌，而是压力分辨率与有效面积共同决定的结果。

## 4. 四个集成点与验收方法

| 工位 | 执行元件作用 | 关键参数 | 验收方法 |
| --- | --- | --- | --- |
| 晶圆搬运/上下料 | 取放升降，避免碎片 | 重复定位 ±0.005mm（实测 ±0.008mm）、速度 20~80mm/s | 激光位移计打表，连续 50 次取极差 |
| 探针接触力 | 下压至设定力并保持 | 2.4g 级台阶可分辨、响应 ≤10ms | 力传感器阶梯加载，记录超调与稳定时间 |
| 光学调焦 | Z 向微进给，保持焦面 | 0.5mm/s 以下无爬行 | 三点低速测试，速度波动 ≤ ±0.1mm/s |
| Z 轴重力平衡 | 抵消镜组与主轴自重 | 全行程力线性度 | 断电保压测试 + 全行程加载 |

### 4.1 搬运与上下料

重点在节拍与冲击。取放瞬间的加速度会在晶圆上产生惯性冲击，薄片尤其敏感。工程做法是分段速度曲线：接近段降到 5mm/s 以下，接触段用 0.05~0.1MPa 的低压建立柔性接触，避免硬碰撞。重复定位精度受导轨与安装基准影响大于气缸本身，±0.005mm 是元件能力，整机实测常落在 ±0.008mm，差值来自机构刚性。

### 4.2 探针接触力

针尖允许的接触力通常在克力到数十克力，超过阈值就出现针痕过深甚至焊盘击穿。传统做法是在下压段加弹簧或力传感器做被动限力，代价是行程长、响应慢。用低摩擦气缸把压力直接映射为力，可以把设定力简化为设定压力一个参数：调压阀拧到对应刻度即得到目标力，无需闭环。前提是摩擦死区足够小，否则刻度与力不呈线性。

### 4.3 光学调焦

调焦段的运动特征是低速、微行程、频繁换向，正是接触式气缸最容易爬行的区间。0.3mm/s 的指令速度下，实际位移常呈阶梯状，图像清晰度随阶梯跳动。气膜结构在该区间可保持连续运动，0.5mm/s 以下无爬行，配合 ±0.1mm/s 的速度精度，焦点漂移可控制在景深内。

### 4.4 Z 轴重力平衡

镜组与主轴自重需要恒定抵消力。气膜气缸的出力与压力近似线性，可在全行程保持平衡力稳定；断电时气路保压，Z 轴不会自由下落，意外断电场景下比机械配重更安全。工程上常以气浮配重替代部分电机负载，实测可使电机发热量下降 50% 以上。

## 5. 气源与洁净度规范

| 层级 | 过滤精度 | 作用 |
| --- | --- | --- |
| 一级 | 5μm | 拦截管道锈渣与密封碎屑 |
| 二级 | 0.3μm | 拦截油雾与细颗粒 |
| 三级 | 0.01μm | 末端精滤，保护气膜间隙 |

按 ISO 8573-1，上述三级组合对应 Class 1；前道设备常要求 Class 0，需在末端再加活性炭与超精滤并监测露点。气膜间隙在微米级，0.01μm 之后若仍有油雾，会在缸壁累积成膜，等效粗糙度变差，气膜稳定性随之下降。这是现场最容易被省掉的一层。

## 6. 集成检查清单

安装前：

- 缸壁与活塞无磕碰、无划伤，Ra 复检合格
- 气源三级过滤到位，末端压力表读数稳定
- 调压阀为精密型（分辨率 ≤0.12KPa），非普通减压阀
- 安装基准面平面度满足要求，气缸与负载同轴

调试：

- 0.05MPa 起步，逐级升压确认启动点
- 三点低速测试（0.1 / 0.5 / 1 mm/s），记录速度波动
- 阶梯加载，记录力分辨率与超调量
- 全行程力线性度，偏差 ≤ ±2%

量产点检：

- 每班次首件力值核对
- 每周末端滤芯压差检查
- 每月启动压力复测，相对基线漂移 ≤ 10%

## 7. 故障模式与排查

| 现象 | 常见根因 | 处置 |
| --- | --- | --- |
| 低压力段不出力 | 摩擦死区偏大 / 调压阀分辨率不足 | 复测启动压力；更换精密调压阀 |
| 低速抖动 | 气膜不稳定 / 气源含油 | 检查末端精滤与缸壁状态 |
| 力值随行程漂移 | 气路压降 / 补偿气路堵塞 | 检查内部气路与接头 |
| 断电后 Z 轴下沉 | 保压回路泄漏 | 单向阀与蓄能罐气密复检 |
