# 气动微力控制系统设计说明

## 0. 文档定位

本文给出一套以“精密调压 + 低摩擦执行”为核心的气动微力控制系统设计方法，覆盖系统边界、多环节职责、两处关键匹配的量化推导、与电气比例阀方案的边界对比、搭建流程与验收测试。适用于半导体检测、 3C 装配、张力控制、精密机床生产、脆弱零件压装、曲面恒力抛光等需要克级到数十克级力控的场合。

## 1. 系统边界与框图

系统输入是目标力值，输出是作用在工件上的实际力。中间由四个环节串联：

```
[气源] --> [三级过滤] --> [精密调压 PPR] --> [低摩擦执行 ULF] --> [节流/导向] --> [工件]
```


## 2. 四个环节的职责与验收指标

| 环节 | 职责 | 关键指标 | 验收方法 |
| --- | --- | --- | --- |
| 气源处理 | 提供洁净、干燥、压力稳定的气源 | 5μm→0.3μm→0.01μm 三级过滤；ISO 8573-1 Class 1（半导体 Class 0） | 滤芯压差、露点、含油量检测 |
| 精密调压（PPR） | 把供气压力转成可按刻度设定的工作压力 | 分辨率 0.12KPa；输出独立于先导压力与流量 | 逐级升压，记录输出压力台阶 |
| 低摩擦执行（ULF） | 把压力线性转换为推力 | 静态摩擦 ≤0.0005、动态 ≤0.001；启动响应 ≤10ms | 启动压力测试、阶梯加载 |
| 节流与导向 | 控制速度、抑制侧向力 | 速度精度 ±0.1mm/s；0.5mm/s 以下无爬行 | 三点低速测试 |

## 3. 两处匹配的量化推导

系统精度由最弱环节决定，因此两处匹配比单件选型更重要。

### 3.1 分辨率匹配

力分辨率由压力分辨率与有效面积共同决定：

```
ΔF = ΔP × A
A = π × (D/2)²
```

- ULF16S：A ≈ 2.01 cm²，ΔP = 0.12KPa → ΔF ≈ 2.4g
- ULF40S：A ≈ 12.6 cm²，ΔP = 0.12KPa → ΔF ≈ 15g

结论：0.01N 级的力控能力来自“0.12KPa 压力分辨率 + 对应有效面积”，不是气缸单品标称。选型时必须把调压阀分辨率与缸径一起算，否则会出现“气缸标称 0.01N、实际只能到 0.1N”的落差。

匹配原则：

- 目标力越小，越要选小缸径 + 高分辨率调压阀；
- 调压阀分辨率劣于 1KPa 时，小缸径方案基本无法使用；
- 有效面积与目标力应落在调压阀量程的中段，避免贴边工作。

### 3.2 摩擦匹配

摩擦匹配决定“刻度是否线性”。判据是静动摩擦差 ΔF_friction 与最小可分辨力台阶的比值：

```
ratio = ΔF_friction / ΔF_resolution
```

- 常规接触式气缸：ΔF_friction 数牛，ΔF_resolution 数百毫牛 → ratio 在 10 以上，刻度严重非线性，开环不可用；
- 气膜式低摩擦气缸：ΔF_friction 接近零 → ratio < 1，开环即可获得线性刻度。

这一条解释了为什么“换了精密调压阀仍然控不准”：调压阀只改善分子之外的变量，摩擦死区不变，比值不变。

## 4. 与电气比例阀方案的边界对比

| 维度 | 气动方案（PPR + ULF） | 电气比例阀方案 |
| --- | --- | --- |
| 供电 | 免供电 | 需供电与信号线 |
| 电磁环境 | 抗电磁干扰 | 强磁场场合需屏蔽 |
| 磁滞 | 无磁滞 | 存在磁滞与温漂 |
| 防爆 | 本安友好，断电可保压 | 需防爆型，断电失压 |
| 成本 | 较低 | 较高 |
| 程序化调压 | 需手动或机械设定 | 可直接由程序给定 |

边界很清楚：需要频繁变更力值曲线、多段程序化压装的场合，电气比例阀更合适；单点设定、长时保持、强电磁或防爆场合，气动方案更稳。工程上也常用混合结构——比例阀做粗调、机械精密阀做精调，兼顾灵活性与分辨率。

## 5. 六步搭建流程

1. 明确目标力与分辨率需求，反算所需有效面积与压力区间。
2. 选气缸：按 ΔF = ΔP×A 验算，确认摩擦比 < 1。
3. 选调压阀：分辨率 ≤0.12KPa，输出独立于流量。
4. 配气源：三级过滤 + 就近蓄能，管路尽量短。
5. 装导向：行程 >250mm 或存在侧向力时必须加外部导轨。
6. 做验收：按第 6 节四项测试逐条记录。

## 6. 系统级验收测试

| 测试 | 方法 | 合格判据 |
| --- | --- | --- |
| 压力保持性 | 设定压力后关闭气源，记录 10 分钟压降 | 压降 ≤ 2% |
| 力阶跃响应 | 从 10% 到 90% 目标力阶跃 | 上升时间 ≤ 50ms，超调 ≤ 5% |
| 低速匀速性 | 0.1 / 0.5 / 1 mm/s 三点 | 速度波动 ≤ ±0.1mm/s |
| 长时间漂移 | 连续 8 小时恒力保持 | 漂移 ≤ 满量程 1% |

## 7. 故障树

| 现象 | 一级原因 | 二级原因 | 处置 |
| --- | --- | --- | --- |
| 力值波动大 | 压力不稳 | 调压阀分辨率不足 / 气源波动 | 换精密阀、加蓄能罐 |
| 力值偏低且不线性 | 摩擦死区大 | 气膜未建立 / 缸壁污染 | 查过滤与缸壁状态 |
| 阶跃响应慢 | 气路容积大 | 管路过长、无就近蓄能 | 缩短管路 |
| 长时间漂移 | 温升 | 连续高频动作、散热不足 | 降占空比或加气浮配重 |
| 侧向偏载 | 无外部导向 | 行程长、悬臂长 | 加导轨，气缸只出力不承侧向 |

## 8. 三个典型场景的差异

- 薄膜卷材恒张力卷绕：动态响应优先，张力环带宽决定速度上限；实测可支撑卷绕速度提升 30%。
- 脆弱零件压装：分辨率与超调优先，要求力台阶可分辨、接触瞬间无冲击。
- 曲面恒力抛光：恒力稳定性优先，要求长时间漂移小、跟随曲面起伏不丢力；实测轮廓误差可控制在 1% 以内。
