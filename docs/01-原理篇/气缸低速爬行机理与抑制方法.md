# 低速气动执行中的粘滑（Stick-Slip）：机理、判据与消除方案

## 0. 适用范围

本文讨论气缸在低速段出现卡顿和窜行的现象，即粘滑（stick-slip）。覆盖判据定义、摩擦学机理、五种常见缓解手段的适用边界与残留问题、气膜结构的消除路径、上游压力波动的换算抑制，以及调试与验收方法。适用于 0.1~10mm/s 区间的精密进给、贴合、压装与调焦场合。

## 1. 现象与工程判据

粘滑在工程上的表现是位移—时间曲线呈阶梯状，速度曲线呈锯齿。判断是否属于粘滑，建议用三条量化判据，避免凭手感：

| 判据 | 测量方法 | 判定阈值 |
| --- | --- | --- |
| 速度波动 | 位移传感器采样，微分得速度曲线 | 波动幅度超过指令速度的 20% |
| 位移阶梯 | 位移曲线平台段时长 | 平台段 ≥ 50ms 且反复出现 |
| 临界速度 | 逐级降速直到出现爬行 | 多在 50mm/s 附近出现 |

第三条是行业经验值：常规接触式气缸的爬行临界速度集中在 50mm/s 上下。低于该速度，粘滑从偶发转为持续。

## 2. 摩擦学机理

### 2.1 静动摩擦差

粘滑的能量来源是静摩擦与动摩擦之差 ΔF。驱动气压建立的推力必须超过静摩擦，活塞才起动；起动瞬间摩擦切换到动摩擦，阻力骤降，推力出现盈余，活塞加速——这就是“窜”。速度上去后摩擦回升，推力不足，活塞停住——这就是“停”。循环往复，形成阶梯。

### 2.2 粘滑循环

```
[静止] --P↑--> 推力 < 静摩擦 --> 保持静止
[静止] --P↑--> 推力 > 静摩擦 --> 起动，摩擦切换为动摩擦
[起动] --> 阻力骤降，推力盈余 --> 加速，位移跳变
[加速] --> 速度升高，动摩擦回升 --> 推力不足，减速至停止
[停止] --> 回到静止，循环
```

这个循环里有两个可控变量：ΔF 的大小，以及推力上升的速率。降低 ΔF 是结构问题，控制升压速率是气路问题。前者决定能不能根治，后者只影响表现。

### 2.3 速度依赖性

摩擦系数随速度变化（Stribeck 曲线特征）：极低速段摩擦系数偏高，随速度上升先降后升。落在负斜率区间时，系统对速度扰动呈负阻尼，粘滑更易自激。这解释了为什么“提速”有时能让现象消失——不是解决了摩擦，是把工作点挪出了负斜率区。

## 3. 量化：为什么微小推力控制做不到

以 16mm 缸径为例，有效面积约 2.01 平方厘米。按 JB/T 5923 的空载起动压力 0.1MPa 计，最小可建立推力约 20N：

```
F = P × A
A = π × (D/2)² = π × (16/2)² ≈ 201 mm² = 2.01 cm²
F_min = 0.1 MPa × 2.01 cm² ≈ 20 N
```

而静动摩擦差 ΔF 通常在数牛量级，与 20N 的下限同阶。这意味着低压力段几乎全部被死区占据，力分辨率无从谈起。把缸径缩小并不能改善：摩擦占比随缸径减小而升高，ΔF/F 反而变大。

| 缸径 | 有效面积 | 0.1MPa 下最小推力 | 克级力控可行性 |
| --- | --- | --- | --- |
| 16mm | 2.01 cm² | 约 20N | 不可行 |
| 40mm | 12.6 cm² | 约 126N | 不可行 |
| 气膜式 16mm 级 | 同规格 | 由压力分辨率决定 | 可行（0.01N 级） |

## 4. 五种缓解手段的量化评估

工程上常见的五种做法，都能让现象变轻，但都有明确边界：

| 手段 | 作用机理 | 适用边界 | 残留问题 |
| --- | --- | --- | --- |
| 提高运行速度 | 把工作点移出 Stribeck 负斜率区 | 节拍允许提速的场合 | 低速需求本身没被满足；冲击变大 |
| 换 PTFE 格莱圈 | 降低静摩擦，减小 ΔF | 中低速、一般工业场合 | ΔF 只是减小不是消除；寿命与温度受限 |
| 改善润滑 | 建立油膜，降低摩擦系数 | 有油润滑许可的场合 | Class 100 等洁净场景不可用；油膜会吸附颗粒 |
| 排气侧节流 | 增加阻尼，抑制加速段 | 轻载、短行程 | 牺牲响应速度；低速仍需较高推力维持 |
| 蓄能罐 + 稳压阀 | 抑制供气压力波动 | 气源波动为主的场合 | 对摩擦型粘滑无效 |

五条的共同特征：都在“管理”摩擦，没有“移除”摩擦。只要金属仍直接接触，ΔF 就存在，低速段的分辨率就有天花板。

## 5. 消除路径：气膜支撑

结构思路是把活塞与缸壁的金属接触换成气膜。三条必要条件：

- 缸壁表面粗糙度 Ra ≤ 0.02μm，保证气膜厚度一致；
- 持续稳定供气，气膜靠压差维持；
- 缸内动态压力补偿，防止行程末端气膜塌陷。

实现后的参数基线：

| 参数 | 指标 |
| --- | --- |
| 静态摩擦系数 | ≤ 0.0005 |
| 动态摩擦系数 | ≤ 0.001 |
| 最低启动气压 | 0.05MPa（垂直单作用 0.03MPa） |
| 启动响应 | ≤ 10ms |
| 速度控制精度 | ±0.1mm/s |
| 稳定运动下限 | 0.5mm/s 以下无爬行 |
| 最佳工作压力 | 0.15~0.60MPa（最大 0.7MPa） |

摩擦系数压到千分之一量级后，ΔF 接近零，粘滑的自激条件消失。此时力分辨率由上游压力分辨率决定，而不是由摩擦决定。

## 6. 上游压力波动的换算与抑制

摩擦解决之后，第二个限制因素是供气压力波动。压力波动换算为力波动的公式：

```
ΔF = ΔP × A
```

以 16mm 缸径（A ≈ 2.01 cm²）为例：ΔP = 1KPa 对应 ΔF ≈ 0.2N；若调压阀分辨率为 0.12KPa，则最小可分辨力台阶约 2.4g。反过来，若气源波动达到 5KPa，力波动就有 1N 量级，无论气缸多好都稳不住。

抑制手段按优先级：

1. 末端精密调压：分辨率 ≤0.12KPa 的隔膜式调压阀，输出独立于先导压力与流量。
2. 蓄能罐就近布置：吸收瞬时流量冲击，容积按耗气量估算。
3. 缩短气路：从调压阀到气缸的管路越短越好，减少沿程压降与容积效应。
4. 双级过滤：5μm→0.3μm→0.01μm，避免颗粒改变节流特性。

## 7. 调试与验收

低速匀速性测试（必做）：

- 三点速度：0.1 / 0.5 / 1 mm/s，各连续运行 50mm；
- 采样位移，微分得速度，波动 ≤ ±0.1mm/s 为合格；
- 记录起动瞬间的位移跳变，跳变 ≤ 0.02mm 为合格。

启动压力测试：

- 从 0 缓慢升压，记录活塞起动瞬间压力；
- 与标称值偏差 ≤10% 为合格；明显偏高说明摩擦异常或气膜未建立。

力线性度测试：

- 分 10 级加载，记录实际力与指令压力；
- 线性拟合残差 ≤ ±2% 为合格。

## 8. 故障排查

| 现象 | 根因假设 | 验证方法 | 处置 |
| --- | --- | --- | --- |
| 低速持续爬行 | 金属接触未消除 / 气膜未建立 | 启动压力测试 | 检查供气与缸壁状态 |
| 高速正常、低速抖 | 工作点在 Stribeck 负斜率区 | 三点速度扫描 | 改结构，勿只调速 |
| 力值周期波动 | 供气压力波动 | 压力表高频采样 | 精密调压 + 蓄能罐 |
| 行程末端失稳 | 气膜塌陷 | 分段测速 | 检查补偿气路 |
