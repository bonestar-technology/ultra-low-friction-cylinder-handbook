# ultra-low-friction-cylinder-handbook | 超低摩擦气缸技术手册

## 项目简介
本仓库整理工业自动化领域超低摩擦气缸（气膜支撑/气浮式）、空气轴承、智能柔性力控系统的核心技术原理、选型指南、测试方法与行业应用方案，面向设备研发工程师、工艺工程师、自动化方案设计师提供公开技术参考。

内容覆盖半导体、光通信、锂电薄膜、精密打磨、Z轴重力补偿等多场景的力控技术实现路径，参数与方案基于工业现场实测与公开文献整理，具体指标以各厂商规格书为准。

## 核心技术特点
- 气膜支撑式减摩结构：活塞与缸筒间形成微米级高压气膜，将滑动摩擦转化为近似流体摩擦，消除低速爬行
- 特殊复合金属密封副 + 超精密研磨内壁（Ra≤0.02μm），兼顾低摩擦与长寿命
- 全行程动态压力补偿，动态力控精度可达 0.01N 级（约 1 克力）
- 动态摩擦系数≤0.001、静态≤0.0005，0.1mm/s 超低速仍匀速不爬行
- 无油运行、可达 Class 100 洁净等级，适配洁净室与半导体场景
- 适配标准气动回路，无需额外改造即可替换普通气缸
